# AURA CLASH: Rising Tower

Epic 3D anime arena fighter with a roguelike tower climb. Created by **BaneBamage**.

## Play
Open `index.html` in a browser (works on Android phones and desktop). To host it free, turn on **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root) and play at `https://auto-tech-pro.github.io/AURA-CLASH-Rising-Tower/`.

## Features
- 1v1, 2v2 and 3v3 battles with tag switches
- **VS Online**: 1v1 against another player — Quick match, or Create room / Join room with a 4-letter code (WebRTC via PeerJS, no game server needed)
- **Fullscreen** button on the home and pause menus (remembered), and add-to-home-screen support so the game opens without the browser bar
- 22 fighters (12 SSS class), each with unique combos, heavies, skills, counters and ultimates — new: Kurai, Ikazuchi, Tamamo, Mamushi, Amateru
- Guard button swaps between **Block** and **Charge Ki** (G key or the ⇄ pill on phones)
- Aura Awakening power-up, ki charging, air combos, vanishing step
- Three arenas: Lantern Court, Bamboo Shrine, Molten Forge
- Random battle weather with gameplay effects (rain, thunderstorms with lightning strikes, blizzard, fog, smoke, ash)
- **Rising Tower** mode: 10 floors, roguelike upgrade cards, save and continue
- Tower-only bosses: Raikō the Thunder Colossus (floor 5) and Yami the Hollow Shogun (floor 10)
- Characters tab, match replays, intro showcase and procedural music

## Controls (keyboard)
WASD move · J attack · K heavy · Space jump · L dash · Shift guard/charge · G swap guard↔ki · O counter · U skill · I ultimate · T tag · P moves · Esc pause

On phones, on-screen touch controls appear automatically.

Built with [three.js](https://threejs.org/) r128 in a single HTML file.
